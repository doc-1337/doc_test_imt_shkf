# Калькулятор ІМТ, площі тіла та ШКФ для пацієнтів з ампутаціями

**Інноваційний медичний калькулятор для точної оцінки ключових клінічних показників у пацієнтів з ампутаціями кінцівок.**

## 📝 Опис проєкту

Цей інструмент призначений для лікарів та дослідників. Він розв'язує проблему неточних розрахунків за стандартними формулами, які не враховують ампутації. Калькулятор надає скориговані значення, що дозволяє уникнути помилок в діагностиці та лікуванні.

## ✨ Ключові особливості

- **Унікальна методика**: Розрахунок втрати маси тіла на основі модифікованої методики Osterkamp (2026) з розподілом на третини.
- **Коригування ШКФ**: Розрахунок ШКФ за скоригованим креатиніном згідно з формулою Sydorova N.M. et al. (2025).
- **Детальний вибір ампутацій**: Підтримка вибору ампутованих сегментів кінцівок з розбивкою на третини.
- **Клінічне застосування**: Розроблено у співпраці з НВМКЦ «ГВКГ» та УВМА.
